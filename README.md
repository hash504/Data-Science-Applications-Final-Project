# Interdisciplinary Applications in Data Science Final Project
## Synopsis & Summary
This project is the final project for my Interdisciplinary Applications in Data Science college class, a class provided by North Hennepin Community College, of which I am a graduate of.
The conceit of this project involves comparing the rating values of movies for various aggregate movie review websites: Letterboxd, IMDb, Rotten Tomatoes, and Metacritic. This is done by creating a combined database of 9,000+ movies, all of which have ratings on each website, including audience and critic ratings for Rotten Tomatoes, and exclusively critic ratings for Metacritic (as Metacritic’s rating data is primarily from critics). More details about the why and how and resulting information from this experiment is detailed below.

## Core Project Ideas
To provide further detail on exactly what is being analyzed here, the database consists of, for each movie, a title, release year, genre(s), Letterboxd rating, IMDb rating, Rotten Tomatoes audience and critic ratings, and Metacritic critic ratings. The core idea behind the project is comparing the rating values between websites based on genre and date using summary statistics like mean values, standard deviation, and unique value counts. These summary statistics were used in tandem with data visualizations in order to provide insight regarding trends in data and to compare between each website.

## Technologies Used
The project itself is built entirely in Python using various libraries. The Pandas library is used for creating the database and managing it, it is used with Numpy for summary statistics. The Plotly library is used to create interactive visualizations, mostly in the form of bar graphs. The specifics of how these technologies were used to make summary statistics is displayed in the Summary Statistics section of this writeup.
A few other smaller Python libraries were used, most notably the Kagglehub library for importing data from the Kaggle website. More information about Kaggle will be included in the Data Sources section of this writeup, and descriptions of all minor libraries are included in the project file submitted with this writeup.

## Data Sources
The data used to create the database for the project was imported from the database website Kaggle using the Python library Kagglehub, more specifically the dataset_load() function from the library. The function was used to load datasets from each aggregate review website. Once all the necessary data was pulled, each dataset was merged into one dataset, in the process losing many potential pieces of data to be used, but also ensuring complete consistency by filtering out null values and obscure films. The combined database includes over 9,000+ values, and features zero null values or anomalous outliers.
More details of the specifics of the dataset_load() function are included in the project file submitted with this writeup.
The main reason I chose Kaggle as the primary data source was due to its reliability, as it is a website that contains thousands of publicly available datasets, and due to the convenience of the Kagglehub library allowing for easy conversion from online database to Pandas dataset.

## Summary Statistics
Summary statistics were primarily collected using the Pandas function describe(), which displays various summary statistics (count, mean, standard deviation, 25th, 50th and 75th percentiles, and min and max values). Using the describe function on the combined database served as a solid basis for analyzing and comparing rating values between websites.

## Applications of Data Science to Another Discipline
The primary reason why I chose to analyze aggregate movie review websites is for two reasons. Firstly, it aligns with my interest in movies, especially since I am an active user of one of the aggregate movie review websites (Letterboxd), and secondly, this project served as an opportunity to expand upon a previous project from a previous class. The previous project was a Statistics project with the same general idea, though with a larger focus on statistical analysis and a much smaller, pseudo-randomly selected dataset. 
As for how a project like mine can apply to other disciplines, given that it heavily involves the summary statistics of the rating values of movies, it could serve as a basis for decision making in the marketing or entertainment industries. For example, imagine a hypothetical insight derived from my dataset is that Action movies are becoming more highly regarded in recent years. A marketing manager could use it as an opportunity to invest in action movies. Whether any of the insights will actually influence decisions is up to whoever may potentially come across this dataset, but the potential applications of data science to other disciplines is there.

## Conclusion
Insights I derived from the created dataset will be included in the project file, so I will use this section to explain what I determined about this project after making it.
My secondary objective of using this project in order to expand on a previous project was a success. However, I still think that there is more to expand upon with the core ideas of the project. Originally, I was planning to use APIs to collect data from each aggregate review website, but this proved to be impossible as websites either had private APIs, costly APIs, or both. The most obvious way to expand upon the core project ideas would be to use APIs to collect more data, significantly increasing the sample size of the dataset. More complex statistical operations can also be used to prove the reliability of certain insights.
Despite the potential for expansion being very high, I still think this project is a complete package, featuring a reliable and large dataset and applying the core concepts of data science appropriately.
